LAYLA LOVE LEO

Files:
- index.html : the full website
- song.m4a   : the uploaded audio file, renamed for easier linking

To preview, keep both files in the same folder and open index.html.
To publish on a static host, upload both files together (or upload the ZIP contents after extracting).

Note: The audio player is wired to song.m4a. If the uploaded clip is not the exact song/segment you wanted, replace song.m4a with your preferred audio file while keeping that filename.
